# Namma-Santhe Ledger

## 📌 Project Description
Namma-Santhe Ledger is an AI-powered Android application developed for small vendors and rural market sellers to manage customer credit (“Udari”), track payments, and monitor daily profit/loss digitally.

The application replaces traditional handwritten khata systems with a simple and efficient digital solution for better financial management.

---

# 🚀 Features

- Customer Ledger Management
- Credit and Payment Tracking
- Daily Profit/Loss Summary
- Profile and Settings Management
- Modern UI using Jetpack Compose
- Transaction History Tracking

---

# 🛠️ Tech Stack

- Language: Kotlin
- Framework: Android Studio
- UI: Jetpack Compose
- Database: Room Database
- Architecture: MVVM
- Tools: Firebase, Android SDK
